El concepto

Qué es y por qué existe

El problema, el enfoque y el alcance real del proyecto.

Mega Free Chat es una aplicación web local que descubre en ejecución los modelos con precio $0 del catálogo de OpenRouter, los mantiene en un pool en memoria y envía cada pregunta al primero que acepte la petición, con prioridad a proveedores chinos y failover por modelo. Expone una UI de terminal, tres endpoints (/api/models, /api/chat y /) y streaming SSE. Está pensada para una persona en una máquina de confianza que quiera probar modelos gratuitos sin editar listas.

El interés está en la política: filtro literal de pricing == "0", clasificación china con regex ancladas, cooldown doble para 429 y estado por modelo en lugar de global. No es multiinquilino, no mide calidad ni latencia, no guarda historial y no sustituye un modelo pago en silencio: si el pool queda vacío, devuelve un error explícito. Depende de que OpenRouter mantenga modelos gratuitos, condición que puede cambiar.

Cómo leer esta ficha

Los tropiezos salen de la bitácora y de las versiones tempranas. La evaluación usa seis criterios fijos, de 1 a 5, y no premia la espectacularidad: premia que el proyecto se pueda reproducir y entender.

01 — La idea

Un chat que no se cae cuando un modelo se cae

La gracia no es el chat: es la capa que elige, rota y mantiene la conversación viva cuando el proveedor gratuito falla.

El problema

Los modelos gratuitos de OpenRouter son excelentes hasta que desaparecen: 429, timeouts, modelos que dejan de estar disponibles. Un chat que depende de uno solo se rompe en la primera demo.

La solución

Un pool con prioridad china, failover automático y streaming SSE. Si el modelo activo falla, la pasarela elige otro y continúa la respuesta sin que el usuario recargue la página.

02 — El recorrido

Cómo funciona, paso a paso

El usuario escribe; la pasarela decide quién responde.

01

El navegador envía

La UI manda el historial al backend por HTTP y abre un stream SSE para la respuesta.

02

El pool elige

El backend consulta el catálogo de modelos gratuitos y prioriza los modelos chinos disponibles.

03

La respuesta fluye

Los tokens llegan por SSE y se pintan en la burbuja sin esperar al final.

04

Si falla, rota

Un error 429 o un timeout cambia el modelo y reintenta. El usuario ve una respuesta, no un stack trace.

03 — Bajo el capó

La pasarela es el producto

El frontend es simple a propósito; la inteligencia de selección vive en el backend.

Streaming SSE

La respuesta se muestra mientras se genera, con eventos claros y reconexión.

Prioridad china

El pool ordena modelos chinos gratuitos primero, pero conserva alternativas globales.

Failover visible

Los errores se registran y se convierten en una nueva elección de modelo, no en una pantalla rota.

Tropiezos

Los tropiezos, documentados

Lo que no funcionó en las primeras versiones, con la corrección aplicada.

commits 2–3 · alcance

Firmware ESP8266 dentro del repositorio web

El segundo commit añadió una API para microcontroladores y el firmware del ESP8266, lo que obligaba a clonar un dispositivo para leer el backend. Se separó en proxy-openrouter-ia-chinas con un commit propio el mismo día, antes de que el alcance creciera.

v1.0 · failover

El failover no cubre el primer intento

chat_stream es un generador: llamarlo no ejecuta la petición, así que los except del router nunca ven el 429 del primer modelo. Se descubrió escribiendo la documentación y no en ejecución; quedó sin corregir como deuda prioritaria, con dos fixes descritos.

v1.0 · configuración

load_dotenv() llega tarde

Los módulos leen os.getenv al importarse y el .env se carga después; con uvicorn server:app se ignoran BACKOFF_SECONDS, POOL_REFRESH_SECONDS y OR_BASE_URL. Se documentó en README, datasheet y developer, pero el cambio a lectura en runtime no está aplicado.

2026-08-28 · clasificación

Falsos positivos de modelos chinos

La keyword "ling" (Ling/InclusionAI) coincidía dentro de "inkling", así que modelos occidentales aparecían como chinos en el panel. Las keywords se convirtieron en expresiones regulares con límite de palabra.

Preguntas

Lo que suelen preguntar

¿Qué es Mega Free Chat?

Una pasarela web local que consulta el catálogo de OpenRouter, filtra los modelos con precio $0 y enruta cada mensaje al primero disponible, entregando la respuesta por SSE.

¿Garantiza IA gratuita?

No. Se apoya en promociones del catálogo de OpenRouter; si no queda ningún modelo en $0, la app responde con un error explícito en lugar de usar un modelo pago.

¿Cómo se ejecuta?

Con python3 -m venv, pip install -r requirements.txt y run.sh o uvicorn; hay que definir OPENROUTER_API_KEY en .env y abrir localhost:8000.

¿Qué se puede reutilizar?

El pool dinámico con cooldown por modelo, la clasificación por proveedor y keyword, y el contrato SSE con eventos status, chunk, done y error.
